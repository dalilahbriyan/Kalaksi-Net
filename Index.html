1. Konsep Alamat IP (IPv4)

Alamat IP (Internet Protocol Address) adalah identitas numerik yang diberikan kepada setiap perangkat (komputer, HP, router) yang terhubung ke jaringan berbasis TCP/IP.

Struktur Bit IPv4:

  • Panjang total: 32 bit biner.
  • Dibagi menjadi 4 Oktet (tiap oktet = 8 bit).
  • Format desimal titik: 192.168.10.1

Pembagian Kelas IP (Classful):

Kelas Oktet 1 Default Mask
Kelas A 1 - 127 255.0.0.0 (/8)
Kelas B 128 - 191 255.255.0.0 (/16)
Kelas C 192 - 223 255.255.255.0 (/24)

IP Public vs IP Private:

IP Public: Alamat unik global internet luas.

IP Private (LAN): Digunakan internal sekolah/rumah (RFC 1918):

• A: 10.0.0.0 - 10.255.255.255
• B: 172.16.0.0 - 172.31.255.255
• C: 192.168.0.0 - 192.168.255.255

2. Subnetting & CIDR (Classless)

Subnetting adalah teknik membagi satu jaringan komputer besar menjadi beberapa sub-jaringan (Subnet) yang lebih kecil.

4 Unsur Hasil Subnetting:

  1. Network ID: Alamat pertama identitas kelompok.
  2. Subnet Mask: Penentu batas network dan host.
  3. Broadcast ID: Alamat terakhir penyiaran paket.
  4. Range Host: Alamat IP valid yang dipasang ke PC.

Rumus Utama Subnetting:

• Jumlah Subnet = 2^x (x = bit 1 oktet terakhir)
• Jumlah Host/Subnet = 2^y (y = bit 0)
• Usable Host = (2^y) - 2
• Blok Subnet = 256 - Netmask

3. VLSM (Variable Length Subnet Mask)

VLSM memungkinkan setiap subnet memiliki panjang netmask berbeda sesuai kebutuhan aktual jumlah host tiap ruangan.

Langkah Perhitungan VLSM:

  1. Urutkan kebutuhan host dari terbesar ke terkecil.
  2. Cari prefix CIDR terhemat (2^y - 2) ≥ Host.
  3. Alokasikan Network ID mulai dari IP induk awal.
  4. Hitung Broadcast ID, lalu tentukan IP subnet berikutnya.

4. Kebutuhan Bandwidth & Throughput

Bandwidth adalah kapasitas maksimal transfer data (Mbps). Throughput adalah kecepatan riil bersih yang dialami user.

Standar Alokasi per User:

  • • CBT / Browsing Teks ➔ 512 Kbps (0.5 Mbps)
  • • Streaming Video 720p HD ➔ 2 Mbps
  • • Zoom Meeting / Video Call ➔ 5 Mbps
